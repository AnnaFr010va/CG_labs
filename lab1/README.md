# Лабораторная работа №1. Цветовые модели

Графическое приложение на Python (PyQt5) для конвертации цветов между тремя цветовыми моделями: **CMYK**, **RGB** и **HSV**. Приложение позволяет просматривать и редактировать цвет в разных моделях и выбирать его из палитры.

## Функциональность

### Конвертация между цветовыми моделями

- **CMYK** — Cyan, Magenta, Yellow, Key (Black)
- **RGB** — Red, Green, Blue
- **HSV** — Hue, Saturation, Value

### Визуальное представление

- предпросмотр текущего цвета;
- ползунки для плавного изменения компонент;
- поля для точного ввода значений;
- палитра (квадрат насыщенности и яркости, полоса тонов);
- набор базовых цветов;
- поле HEX-кода цвета.

### Синхронизация данных

- автоматическое обновление всех моделей при изменении любой компоненты;
- контроль вводимых значений: значения не выходят за допустимые диапазоны;
- защита от циклических обновлений.

## Использование

### Панели цветовых моделей

Каждая компонента задаётся ползунком или полем ввода.

- CMYK: C, M, Y, K (0–100 %)
- RGB: R, G, B (0–255)
- HSV: H (0–360°), S, V (0–100 %)

### Базовые цвета

Красный, жёлтый, зелёный, голубой, синий, пурпурный. Цвет выбирается щелчком по образцу.

### Палитра и предпросмотр

- выбор цвета щелчком или перетаскиванием мыши по палитре;
- отображение текущего цвета;
- ввод цвета в виде HEX-кода, например `#FF0000`.

## Вывод

В ходе работы были изучены цветовые модели CMYK, RGB, HSV и преобразования между ними. Разработано приложение, которое позволяет задавать цвет полями ввода, ползунками и палитрой, автоматически пересчитывает его во всех трёх моделях и контролирует вводимые значения.
